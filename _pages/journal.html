第一次使用：如何准备 GitHub Token？
  1. 打开 GitHub 的 Fine-grained Token 设置，设置有效期。
  2. Repository access 选择 Only select repositories，只选上面填写的仓库。
  3. Repository permissions 中把 Contents 设置为 Read and write，生成后粘贴到这里。

默认使用主页仓库，也可以填写另一个已初始化的私有仓库。公开仓库里的密文可被下载，务必使用强 key。Token 和 key 是两件不同的东西。

标题、日期和正文都会加密。GitHub 仍会记录文件大小、提交时间和历史版本；删除日记不会抹去历史密文。此页面不加载第三方脚本。
